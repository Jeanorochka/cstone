# Changelog

## 0.2.0 — 2026-11-01

- Multi-architecture assembler MVP: x86-32/64, AArch64, ARM, Thumb, RV32/64 and little/big-endian MIPS32/64.
- Bounded input API, resource limits, exported labels and transactional external relocation linking.
- Memory operands, additional integer instructions, data and alignment directives.
- Shared/static library builds, CMake installation and package discovery.
- Architecture selection, JSON, stdin and Unicode Windows filenames in the CLI.

## 0.1.0 — 2026-11-01

- Initial standalone C x86-64 assembler prototype.
